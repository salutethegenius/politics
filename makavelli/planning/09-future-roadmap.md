# Future Roadmap

## 1. Team & multi-tenancy

- Workspaces / organizations.
- Invitation flows and role-based access.
- Shared nodes with per-user permissions.
- Audit logs and admin dashboard.
- Activity feed across team members.

## 2. Commercial productization

- Rebrand internal "Makavelli" to public **Verity Nexus**, **Verity Graph**, or **Verity Command**.
- Stripe billing and subscription tiers.
- Self-serve signup and onboarding.
- Public landing page and product docs.
- API keys and usage limits.

## 3. Intelligence & AI

- Persistent AI conversation threads.
- Automated weekly briefings based on upcoming meetings and follow-ups.
- Predictive opportunity scoring.
- Relationship decay warnings (contacts not touched in N days).
- Automated graph enrichment from documents and emails.
- Voice / meeting transcription and summary.
- AI-generated graph insights (central players, bridge opportunities, ministry gaps).

## 4. Integrations

- Email provider integration (Gmail / Outlook) for automatic meeting/contact extraction.
- Calendar sync (Google Calendar, Outlook, CalDAV).
- Document storage (Google Drive, Dropbox, S3/R2).
- Government data sources (Bahamas Gazette, GBPA, bahamasopendata.com).
- CRM import (HubSpot, Pipedrive, Salesforce).
- Slack / Teams notifications.
- Zapier / Make.com support.

## 5. Advanced graph features

- Centrality, betweenness, and community detection.
- Pathfinding between two nodes.
- Time-based graph (show relationships by date).
- Geospatial graph layer for locations and districts.
- Saved graph views and filters.
- Graph-based reporting and export.

## 6. Scale & enterprise

- Dedicated Neo4j clusters.
- Read replicas for Postgres.
- Edge caching and CDN.
- SOC 2 / security compliance groundwork.
- Custom fields and schemas per organization.
- Enterprise SSO (SAML, OIDC).
- Data residency controls.
- On-premise deployment option.

## 7. Ecosystem

- Public API for third-party developers.
- Plugin marketplace for custom node types and AI skills.
- Mobile app (iOS / Android) with offline support.
- Browser extension for clipping web pages into research nodes.
- Desktop app (Electron or Tauri) for local-first option.

## Guiding principle for all future work

Every feature must strengthen the relationship graph. Documents are secondary. The product wins when the user can see, query, and act on their entire strategic network in one place.
